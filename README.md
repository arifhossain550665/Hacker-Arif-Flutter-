# Flutter WebView Project

এই প্রজেক্টটি একটি প্রফেশনাল Flutter WebView App Structure।

## কিভাবে URL পরিবর্তন করবেন?
`lib/main.dart` ফাইলের ভেতরে `myUrl` ভেরিয়েবলে আপনার কাঙ্ক্ষিত ওয়েবসাইট URL বসিয়ে দিন:

```dart
final String myUrl = 'https://yourwebsite.com';
```

## যেভাবে রান ও বিল্ড করবেন:
1. `flutter pub get`
2. `flutter run`
3. APK বিল্ড করতে: `flutter build apk --release`
